Fleiss' kappa

Inter-rater agreement for nominal categories. Each row is one subject; each column counts the number of raters assigning that category. Runs entirely in your browser.

Rating data

Every row must have the same number of category columns and the same rater-count total (at least 2).
Supports category headers c1, c2 or v1, v2. Other columns are ignored. Maximum file size: 1 MB.
